# 雅思A类机考阅读
## 考试基本资讯

**界面操作细节**
- **分屏布局**：
  - 屏幕左侧显示完整文章，右侧显示题目。文章和题目各自独立滚动，互不影响，可随时对照。
  - 文章右侧有滚动条，下方有“回到顶部”按钮，方便快速定位。
- **高亮与标注功能**：
  - 选中文章中的词或句，点击右键选择“Highlight”可添加黄色底色高亮，再次右键可取消。
  - 在文章任意位置右键选择“Notes”，可弹出小窗输入文字标注（如某段主旨），标注过的段落左侧会出现黄色标签，点击标签即可查看笔记。
- **题型交互方式**：
  - 判断题（TRUE/FALSE/NOT GIVEN）、选择题：直接点击选项。
  - 填空题、简答题：从文章中选中单词或短语后，可使用`Ctrl+C`复制，然后`Ctrl+V`粘贴到空格内，也可手动输入。**强烈推荐复制粘贴，避免抄错单词**。
  - 标题匹配、信息配对：拖拽选项到对应段落或题目编号上，部分也可在下拉菜单选择。
  - 完成摘要题（有选项框的）：点击空格，从下拉选项中选择。

**时间管理与导航**
- 屏幕上始终显示倒计时，最后10分钟和5分钟会变红闪烁提示。
- 可通过底部题号栏直接点击跳转任一题目，未做题编号空白，已做变色。

**详细应对建议**
- **分屏阅读需要刻意练习**：
  - 习惯不打印纸质文章，练习一边滚动左侧文章，一边在右侧作答。避免频繁上下翻动，可先通读题干划关键词，再回文章定位。
  - 练习时强制使用分屏模式，纸质书或全屏网页练习无法模拟真实操作感。
- **高亮和笔记的正确用法**：
  - **高亮不过度**：只标记人名、数字、年份、转折词后观点句、专有名词等，每段高亮不超过2-3处，否则失去重点。
  - **笔记只记核心**：笔记窗口较小，仅写极简关键字，如“原因1”“对立观点”，不要写长句，费时且不易看。
  - 雅思阅读答案点通常按顺序出现，定位时若某段高亮密集，可以优先检查该段。
- **填空题必用复制粘贴**：
  - `Ctrl+C`复制原文词，`Ctrl+V`粘贴到空格，几乎消除拼写错误风险。考前务必在模拟系统里练习这个动作，形成肌肉记忆。
  - 注意词数限制，若要求“NO MORE THAN TWO WORDS”，而复制了三个词，需手动删减。
- **攻克拖拽类题目**：
  - 段落标题匹配：建议先读所有选项，再快速浏览每段首二句和尾句，拖拽选项后，该选项从备选栏消失，可排除干扰。
  - 若拖拽失误，可将正确选项拖到错误选项上替换，或点击“复原”按钮。
- **时间分配策略**：
  - 严格按20分钟一篇训练，第一篇较易可控制在17-18分钟，为第三篇留出22-23分钟。
  - 单篇若超时2分钟仍找不到某题答案，先标记Review并跳过，最后有剩余时间再补。
- **判断题巧用键盘**：
  - 部分考场系统支持点击选项后直接按`Tab`键跳下一题，加快速度。练习时可测试是否有效。

## Band 9 Core Skill 1: 结构阅读法
### 一、什么是结构阅读法？
它不是“跳读”或“略读”，而是**主动预判文章逻辑，按功能模块阅读**。  
把一篇文章看作可拆解的“积木”，每一段都有其任务（如：提出观点、举例、反驳、下定义等）。

### 二、核心三步流程

| 步骤 | 操作 | 用时参考 |
|------|------|----------|
| **Step 1 预读骨架** | 看标题、副标题、首段、各段首句、末段 | 1–2 分钟 |
| **Step 2 识别结构** | 在脑中画出文章“地图”：问题→原因→影响→解决 / 新旧观点对比 / 现象解释 | 1 分钟 |
| **Step 3 带题回查** | 根据题目关键词，直接定位到对应功能段，细读相关句 | 按题分配 |

### 三、常见文章结构速查表

| 文章类型 | 典型结构 | 常考题型 |
|----------|----------|----------|
| **议论对比类** | 旧观点 → 新发现 → 证据/实验 → 评价 | 判断题、选择题 |
| **现象解释类** | 现象描述 → 原因/机制 → 影响/应用 | 摘要填空、简答 |
| **问题解决类** | 提出问题 → 解决方案 → 优缺点/结果 | 标题配对、匹配 |
| **事物说明类** | 定义特征 → 分类/举例 → 历史发展/未来趋势 | 图表填空、多选 |

### 四、段落功能快速识别信号词

- **主旨/观点**：首二句或末句，常见 `believe, suggest, argue, conclude`
- **转折/反驳**：`However, But, Yet, On the other hand`（答案常出此处）
- **举例**：`For example, such as, like`（多用于支持前一句观点）
- **因果**：`Because, due to, lead to, result in, therefore`
- **并列/递进**：`First, Second, Moreover, In addition`

读到这些词，立刻标记该句的功能，它决定了附近是否会出现答案。

### 五、分题型应用技巧

1. **List of Headings（标题配对）**  
   ➤ 只读段落**首二句 + 末句**，找出主旨在选项中匹配，不读细节。

2. **Matching（匹配题）**  
   ➤ 先画出所有选项关键词，再回文章按结构分区查找，用信号词定位归属段落。

3. **判断题 / 选择题**  
   ➤ 题干多为顺序出题，利用上一题定位，下一题在同一结构板块后部；对比考点句与原文逻辑（因果、比较、条件）是否一致。

4. **Summary（摘要填空）**  
   ➤ 先判断摘要是全文还是部分段落摘要；通过空前后的逻辑词（and, but, such as）预测词性及内容，回对应结构区域查找同义替换。

> 结构阅读法 = 放弃逐字阅读，改用功能区块阅读。  
> 预判在先，定位在后。文章越难，结构越能救命。

### 📝 結構功能英文標籤速成表

| 中文功能 | 建議英文標籤 | 極速縮寫 (打 Note 用) |
|----------|--------------|------------------------|
| 現象描述 | **Phenomenon / Description** | `Phen` / `Desc` |
| 提出觀點 / 主旨 | **Main Idea / Claim** | `MI` / `Claim` |
| 反駁舊觀點 | **Refutation / Counterargument** | `Refute` / `Counter` |
| 轉折 (新舊對比) | **Contrast / Shift** | `Contrast` / `But` |
| 實驗 / 研究證據 | **Experimental Evidence** | `ExpEv` / `Evidence` |
| 研究結果 / 發現 | **Findings / Results** | `Find` / `Result` |
| 舉例 | **Example / Support** | `e.g.` / `Ex` |
| 因果關係 | **Cause & Effect** | `Cause→` / `∴` |
| 解決方案 | **Solution** | `Soln` |
| 總結 / 結論 | **Conclusion** | `Conc` |

### 💡 實戰用法舉例

喺機考 Note 功能，你可以咁打：

- 見到第一段介紹一個普遍現象：  
  👉 `Phen: many species declining`

- 下一段話「However, new study challenges this view」：  
  👉 `Refute old view / New claim`

- 再下一段詳細講實驗設計同數據：  
  👉 `ExpEv: 2019 trial, 200 subjects`

- 最後總結：  
  👉 `Conc: habitat loss main cause`

💬 **小貼士**：唔使打完整句子，關鍵係**名詞+箭嘴**，自己睇得明就得。例如：
- `Cause→Effect` 
- `Old view → New view`  
- `Problem → Soln`

### 🧠 點樣練習？

用官方模擬試題或者任何機考練習平台，打開 Notes 功能，逼自己每段用一個英文標籤標功能，限時 1 分鐘內標完全文。  
熟咗之後，考試畫結構地圖快到同呼吸一樣自然。

## Band 9 Core Skill 2: 题目压缩

### 一、初阶：精准找出关键词（定位词）
关键词本质分为两大类：**定位词（用来快速锁定原文位置）** 和 **考点词（用来比对逻辑、判断答案）**。定位词求「稳」（原词重现率高），考点词求「准」（直击出题核心），二者缺一不可。

#### 1. 关键词三级分级体系
| 分级 | 词语类型 | 特点与作用 | 典型例子 |
|------|----------|------------|----------|
| **一级定位词（首选）** | 数字、大写专有名词、特殊标识、具象特有名词 | 原文几乎不会同义替换，原词重现率≥90%，是最稳定的定位锚点 | 2015、Professor Sandra Collins、cottage industry、cathedral |
| **二级考点词（核心）** | 逻辑关系词、程度限定词、否定倾向词、核心动作词 | 是题目真正的考察点，大概率会被同义替换，是判断对错的关键 | however、more than、only、fail to、lead to、reduce |
| **三级辅助词（补充）** | 全文主题词、宽泛概括词、普通修饰词 | 单独使用无法精准定位，需与一级词组合使用 | experts、people、study、significantly |

> 机考操作：一级定位词直接用「Highlight」标黄，扫读时一眼即可锁定位置；考点词留在脑中记忆，用来比对答案。

#### 2. 关键词选取四步黄金流程
拿到任何题干，按固定顺序筛选，不会漏选也不会多选：
1. **扫全句抓锚点**：第一时间圈出数字、大写专有名词，锁定大致段落范围
2. **辨考点抓逻辑**：标出否定、比较、因果、绝对词，明确题目考察方向
3. **提主干去修饰**：保留句子主谓宾核心，删掉所有定语、状语、插入语
4. **做组合控数量**：最终保留2-3个关键词为一组，过多会超出短期记忆负荷

#### 3. 六大题型专属关键词策略
不同题型出题逻辑不同，选取侧重点需对应调整：

| 题型 | 核心定位词 | 核心考点词 | 选取技巧 |
|------|------------|------------|----------|
| 判断题 T/F/NG | 数字、专有名词、句子主语 | 比较关系、因果关系、绝对词、否定词 | 主语用来定位，断言部分的限定词是考点 |
| 填空题 Summary/句子填空 | 空格前后的名词、数字、专有名词 | 空格前后的逻辑词（and, but, such as）、词性预判 | 用空格两侧的词双向夹逼定位 |
| 段落信息匹配题 | 选项中的具体名词、专有名词 | 段落功能词（explanation, cause, effect） | 先靠功能词预判段落，再靠名词验证 |
| 标题配对题 List of Headings | 选项中的核心主题名词 | 选项中的态度、逻辑倾向词 | 不读细节，只匹配段落主旨与选项核心名词 |
| 人名观点配对题 | 人名（原词重现，一级定位） | 观点中的核心动词、态度词 | 人名定位段落，观点压缩后比对 |
| 选择题 单选/多选 | 题干的专有名词、段落号 | 选项中的差异点、绝对词、否定词 | 题干定位原文句，选项抓差异点比对 |

#### 4. 机考关键词高亮实操规范
配合机考Highlight功能，严格遵守以下规则，避免越标越乱：
- 单段高亮总词数≤3个，禁止整句、整行标黄
- 一级定位词完整标亮，考点逻辑词只标单词本身
- 确认答案后，可右键取消不必要的高亮，减少后续定位干扰
- 定位顺序：先靠一级词锁定段落 → 再靠二级词锁定句子 → 最后精读比对

#### 5. 常见误区与避坑指南
- ❌ 只划主题词，不划考点词：找到原文后忘了考什么，反复回头读题
  ✅ 纠正：定位+考点同时记忆，找到原文直接比对考点
- ❌ 关键词选太多：一道题划5-6个词，扫读时全部遗忘
  ✅ 纠正：固定2-3个核心组合，配合压缩代码脑记
- ❌ 用全文主题词单独定位：文章通篇讲的主题词满篇都是，无法精确定位
  ✅ 纠正：主题词+限定词组合定位，如 `microplastics + marine life`
- ❌ 删掉否定词、绝对词：遗漏最高频考点，导致句意完全反转
  ✅ 纠正：否定、比较、绝对词必须保留并重点标记

#### 6. 选择关键词的核心原则
- **不可替代性**：数字、专有名词优先，越特殊的词定位越准
- **低频唯一性**：优先选整篇文章中出现次数少的词
- **最多2-3个**：过多超出短期记忆容量，等于没有关键词

### 二、进阶：题目压缩的理论与技巧
**1. 什么是题目压缩？**
将题干长句压缩成只有「定位点 + 考点关系」的极简代码，直接存入短期记忆去扫读原文。

**2. 理论基础**
- **信息冗余理论**：考点只集中在几个词的逻辑链接。
- **认知负荷理论**：将题目压缩至一两个信息块，释放脑力做文意比对。
- **语篇预测模型**：看到压缩后的结构，能够预测原文可能出现的句型。

**3. 题目压缩四步法（TACC）**
- **T – Trim（去修饰）**：删掉不影响核心判断的形容词、副词、举例内容。
- **A – Ascertain（识考点）**：判断题目在问什么——因果？观点？分类？
- **C – Convert（转同义）**：预想原文可能出现的同义替换词。
- **C – Chunk（建组块）**：将剩余信息压成一个「定位区块」。

**4. 各类题型的压缩要点**
- **填空/简答**：空格属性 + 前后定位词。
- **是非无判断**：主语 + 断言点 + 极限词。
- **配对题**：人名不压缩，观点压缩为「动词+核心宾语」。

### 三、机考整合操作流程
1. **读题**：用鼠标高亮2-3个关键词。
2. **心像压缩**：走完一遍TACC流程，或是在Notes面板写下缩写代码。
3. **扫读原文**：带着压缩代码寻找对应区块，留意同义替换。
4. **核对**：回看题目完整句子，确认考点吻合再作答。

### 四、练习建议与注意事项
- 初期练习寻找关键词+高亮，每题限时10秒。
- 中期对比自己的压缩代码和答案句核心词汇。
- 后期计时模考，强制减少重复回看。
- 熟练机考快捷操作，适当调大屏幕字体。

### 五、实战练习与解析

**练习一：关键词识别**
选出每题最合适的**2个**定位关键词，并简述理由。

1. **题干**：*In 2015, Professor Sandra Collins from the University of Toronto published a groundbreaking study on the effects of microplastics on marine life.*
2. **题干**：*The construction of the cathedral was delayed primarily due to a lack of sufficient funding.*
3. **题干**：*Most experts now agree that the earliest form of writing emerged independently in several regions.*

**参考答案与解析**
1. 关键词：**2015, Sandra Collins**。理由：数字与大写人名基本不会改写，是稳定定位点。microplastics与marine life容易出现同义替换，不作为首选。
2. 关键词：**cathedral, funding**。理由：cathedral为特定建筑，辨识度高；funding和延误、资金相关，属于核心考点。lack of sufficient可能替换为inadequate money，稳定性差。
3. 关键词：**earliest form, writing**。理由：earliest属于极限修饰词，极易设置考点；writing是核心主题名词。experts, agree, emerged independently都可能被大幅改写。

**练习二：题目压缩（TACC四步法）**
把下面题干压缩成不超过5组信息的「定位区块」，写出你的压缩代码以及同义替换预判。

**题干**：*The initial investigation into the cause of the fire was carried out by a specially appointed government committee.*

**参考压缩过程**
- **Trim（去修饰）**：去掉specially appointed，保留government committee；核心信息：initial investigation, cause of the fire, carried out by, government committee。
- **Ascertain（识考点）**：谁开展调查？→考点落在执行者。
- **Convert（转同义）**：initial → first/early；investigation → inquiry；cause → origin；carried out by → conducted by / undertaken by；government committee → official panel。
- **Chunk（建组块）**：压缩代码可写 **govt committee + fire cause** 或者 **early inquiry + fire + govt**。

带着这组压缩代码，你需要在原文搜寻类似 “An early official inquiry into the origin of the blaze was conducted by a government panel” 的句子。

**练习三：同义替换与配对**
下文为原文片段和两道题目，请使用压缩技巧快速匹配，找出对应的原文句子，并标出同义替换。

**原文片段**
A. *Prior to the Industrial Revolution, the majority of textile production took place in private homes, a system known as the cottage industry.*
B. *The introduction of the spinning jenny in the 1760s allowed a single worker to operate multiple spools simultaneously, drastically increasing output.*
C. *This mechanisation, however, led to widespread unemployment among skilled hand-weavers, many of whom rioted in protest.*

**题目**
1. 填空题：*Before the 18th century, most cloth was manufactured in ________.*
2. 是非无判断题：*The spinning jenny immediately created jobs for traditional weavers.*

**参考答案**
1. 对应句子 **A**。填空题压缩：“before 18th c. + most cloth + made in ________”。定位词：18th century（同义替换为工业革命之前），most cloth → majority of textile，manufactured → production。答案：**private homes / the cottage industry**。
2. 对应句子 **B 和 C**。判断题压缩：“spinning jenny + created jobs + immediately”。原文说明产量提升，却造成织工失业抗议，和“立刻创造就业”表述相反，答案 **FALSE**。同义替换：created jobs ↔ led to unemployment（反义考点）；immediately ↔ however（转折词，提示后续结果）。

**练习四：综合限时模拟**
请在90秒内运用机考技巧（想象高亮、题目压缩）完成以下配对题。

**人物观点**
- *Dr. Helen Cross*: believes that renewable energy can only replace fossil fuels if storage technologies improve significantly.
- *Prof. Mark Owen*: argues that government subsidies, rather than technological breakthroughs, have driven the recent growth in solar power.

**原文对应段落**
i. “Without major advances in battery capacity, the erratic nature of wind and solar makes them incapable of providing a stable baseline supply,” states Cross.
ii. Owen contends that the expansion of photovoltaic installations owes more to policy incentives than to any engineering innovation.

**配对任务**：*Match each person with the correct statement (i or ii).*

**参考解析**
- Dr. Helen Cross → **i**。观点压缩：renewable energy, replace fossil fuels, storage improve。原文同义：renewable energy → wind and solar；replace fossil fuels → providing stable baseline supply；storage improve → advances in battery capacity。
- Prof. Mark Owen → **ii**。观点压缩：government subsidies drove growth, rather than tech。原文同义：subsidies → policy incentives；technological breakthroughs → engineering innovation；solar power → photovoltaic installations。

## 机考整合操作流程
以下是针对首次使用者的**手把手级实操指南**，我会把每一步的动作、机考工具用法、甚至笔记写什么字、高亮标哪几个词都明确下来，全程适配机考仅有的「黄色萤光笔+笔记」两项功能，你可以直接照着步骤一步步练。

### 第一部分 结构阅读法 零基础机考实操指引
#### 前置：先明确机考工具的使用边界
先把工具规则定死，避免新手常见的「乱高亮、写长笔记」问题，这是Band 9效率的基础：
- **黄色萤光笔**：仅标注2类内容，每段高亮总词数≤3个
  1.  段落核心主题名词（1个）
  2.  强逻辑信号词（最多2个，如`however`/`therefore`）
  ❌ 绝对禁止整句、整行高亮，否则全文一片黄，后续定位会完全失效。
- **笔记（Note）**：统一添加在每段段首位置，内容为「功能缩写+核心主题」，全程用英文缩写/符号，单条笔记不超过3个单词。
  常用固定缩写对照表（直接背下来用）：
  | 缩写 | 完整含义 | 对应段落功能 |
  |---|---|---|
  | Bg | Background | 背景引入 |
  | Cause | Cause / Reason | 原因/成因分析 |
  | Exp | Experiment / Study | 实验/研究论据 |
  | Soln | Solution | 解决方案 |
  | Eff | Effect / Impact | 影响/后果 |
  | Concl | Conclusion | 结论/展望 |
  | × | 否定/反对 | 反方观点/负面评价 |
  | → | 导致/因果 | 因果关系 |

#### 标准执行全流程（单篇3-4分钟完成）
##### 步骤1：主题预判与文体确认（30秒内完成）
**动作**：
1.  读文章标题、副标题、配图说明（如有）
2.  只读首段的前2句话，绝对不往下读
3.  快速判断2件事：① 全文核心主题是什么；② 是说明文还是议论文
4.  用萤光笔标记标题里的核心主题词

**机考操作**：滚动到文章最顶部，选中主题词点击「Highlight」
**合格标准**：能用一句话说清全文大意，例如「这篇讲城市热岛效应的成因和解决办法」。

##### 步骤2：逐段扫读与功能标注（2.5-3分钟，核心环节）
**每一段固定执行7个小动作，单段耗时15-20秒，顺序不能乱**：
1.  **读首句（必做）**：完整读完段落第一句。90%的学术段落首句就是主旨句，直接交代本段核心话题。
2.  **预判功能**：心里快速匹配上文的缩写表，判断这段是背景/成因/实验/方案中的哪一种。
3.  **读尾句（必做）**：完整读完段落最后一句，重点看有没有转折、总结或引出下文。如果尾句出现`however/but`，以转折后的内容为准，修正刚才预判的段落功能。
4.  **扫中间（不精读）**：眼睛快速扫过段落中间，只抓逻辑信号词：
    - 看到`for example / such as / data show`直接跳过——例子永远服务前面的观点，结构阶段不用读
    - 看到`however / but / yet / by contrast`立刻停，用萤光笔标出来——转折后是本段真正核心
    - 看到`therefore / thus / consequently`也标出来——是本段结论句
5.  **写笔记**：在段首添加1条Note，用缩写记录「功能+核心主题」，例如`Cause1: land surface`
6.  **补高亮**：标记本段1个核心名词+最多2个逻辑词，立刻进入下一段

##### 步骤3：特殊段落处理规则（新手最容易卡壳的地方）
遇到不符合「首句主旨+尾句总结」的段落，按以下规则处理，不要慌：
- **过渡段**：首句是「这一观点受到质疑」「除了环境因素，社会因素同样重要」这类承上启下的句子。
  → 处理：笔记标「过渡+下文主题」，立刻往下多读1句，找到真正的本段主旨
- **全例证段**：整段都是一个实验、一个案例、一组数据，没有独立观点句。
  → 处理：笔记标`Exp 支持上段观点`，它的作用就是论证上一段的主旨，不用强行找本段主旨
- **超长段落**（超过10行的大段）：
  → 处理：还是首句+尾句，中间抓2个逻辑词即可。大概率是「主旨+2个分论点+例子」结构，笔记可以简写为`Cause: ①下垫面 ②人为热`

##### 步骤4：结构地图内化（30秒收尾）
全部段落标完后，从头到尾快速滚动一遍，只看自己写的笔记，在脑子里串一遍全文逻辑。
例如：P1背景引入热岛效应 → P2-3讲两个成因 → P4-5讲两个解决方案 → P6结论展望
**合格标准**：提到某个话题（比如“解决方案”），你能立刻说出大概在第几段区间，不用全文盲目滚动。

#### 完整实操示范（模拟真题段落）
以典型说明文《The Urban Heat Island Effect》为例，展示每段的最终标注结果：
> **P1 原文片段**
> The urban heat island effect is a phenomenon where urban areas experience significantly higher temperatures than their rural surroundings. ……（中间是温度数据和城市分布）…… This temperature gap has widened dramatically over the past 50 years due to rapid urbanisation.
- 笔记：`Bg: UHI effect`
- 高亮：`urban heat island effect`

> **P2 原文片段**
> The primary cause of the urban heat island effect is the change of land surface materials. ……（中间举例混凝土、沥青的特性）…… These materials absorb and retain far more solar radiation than natural vegetation.
- 笔记：`Cause1: land surface`
- 高亮：`primary cause`

> **P3 原文片段**
> Beyond physical land changes, anthropogenic heat emission is another key contributing factor. ……（中间讲交通、空调、工业排热）…… However, its impact varies greatly across different seasons and city types.
- 笔记：`Cause2: anthropogenic heat`
- 高亮：`another key factor`, `however`

> **P4 原文片段**
> To mitigate the urban heat island effect, green roof technology has been widely adopted in many European cities. ……（中间讲实验数据和降温效果）…… Despite higher installation costs, its long-term benefits outweigh the initial investment.
- 笔记：`Soln1: green roof`
- 高亮：`mitigate`, `Despite`

#### 新手常见错误与纠正
1.  **忍不住读细节**：看到例子、数据就想读懂，导致单篇结构梳理超过5分钟。
    → 纠正：记住「结构阶段不解题，只搭框架」，所有细节等定位到题目再精读。
2.  **高亮泛滥**：一句话全标黄，等于没标。
    → 纠正：强制每段高亮不超过3个词，只标名词和逻辑词。
3.  **跳过尾句**：只看首句，错过尾句的转折，导致段落功能判断错误。
    → 纠正：把「读尾句」当成固定动作，每段必做，不能省略。
4.  **笔记写长句**：写完整句子浪费时间。
    → 纠正：只用缩写+符号，单段笔记不超过8个字母。

### 第二部分 题干标准化压缩 零基础实操指引
#### 核心认知先摆正
压缩不是「把句子缩写变短」，而是**提取「定位锚点+考点核心」两类解题必需信息，扔掉所有干扰内容**。
压缩完的内容必须同时满足两个作用：① 能帮你快速找到原文位置；② 能帮你判断答案对错。缺任何一个都是无效压缩。

#### 通用四步压缩法（所有题型通用，新手按步骤走不会错）
##### 步骤1：提取一级定位词（找位置用）
优先圈出**原文几乎不会替换、原词重现率≥90%**的词：
- 数字类：年代、百分比、具体数值、时间节点
- 专有名词：人名、地名、机构名、专业术语、特殊概念
- 特殊标识：带引号、斜体的特殊表述
- 具象特有名词：独一无二的事物名词

##### 步骤2：锁定考点词（判对错用）
这是解题的核心，**绝对不能删**，删了找到原文也会做错：
- 否定类：`not, never, fail to, lack, rather than`
- 比较类：`more than, less than, the most, superior to`
- 绝对类：`only, all, fully, merely, exclusively`
- 因果类：`because, lead to, due to, result in`
- 时间范围：`in the past, future, recently, currently`

##### 步骤3：用符号简化逻辑
把逻辑关系转换成符号，减轻记忆负担：
- `→` 表因果、导致
- `>` / `<` 表比较
- `×` 表否定、失败、没有
- `?` 表原因、目的

##### 步骤4：删掉所有冗余修饰
以下内容全部扔掉，不影响解题：
- 定语从句、同位语、分词后置定语（`which/that`引导的修饰）
- 描述性形容词、副词（如`significantly, dramatically`）
- 插入语、举例、补充说明
- 无意义句式框架（如`It is widely believed that...`）

✅ 最终输出固定格式：`定位锚点 / 考点+逻辑`，用斜线分开，前半段找位置，后半段判答案。

#### 分题型逐题示范（带压缩全过程）
##### 1. 判断题（T/F/NG）
**原题**：According to the passage, human activity has caused more damage to New Zealand’s native plants than natural disasters.
1.  定位词：`New Zealand’s native plants`（地名+特有名词，原词重现）
2.  考点词：`more damage than`（比较关系，核心考点）
3.  逻辑简化：人类活动破坏 > 自然灾害破坏
4.  删除冗余：`According to the passage`
✅ 压缩结果：`NZ native plants / human damage > natural disasters`

##### 2. 填空题（句子填空/Summary）
**原题**：In the 1980s, a team of medical researchers discovered that a certain type of ________ was able to reduce the risk of heart disease significantly.
1.  定位词：`1980s`, `medical researchers`, `heart disease`
2.  考点词：`reduce the risk`（空格的作用）
3.  逻辑简化：____ → 降低心脏病风险；预判词性：名词
4.  删除冗余：`a team of`, `a certain type of`, `was able to`, `significantly`
✅ 压缩结果：`1980s researchers / ____ reduce heart disease risk + n.`

##### 3. 段落信息匹配题
**原题**：an explanation of how industrial agricultural practices lead to the decline in global soil quality
1.  定位词：`industrial agricultural practices`, `soil quality`
2.  功能考点：`explanation of cause`（原因解释，对应成因段）
3.  逻辑简化：工业农业 → 土壤质量下降
4.  删除冗余：`an explanation of how`
✅ 压缩结果：`industrial agriculture / soil quality decline cause`

##### 4. 单项选择题
**原题**：According to the third paragraph, why did the traditional farming method fail to be widely adopted in rural Africa?
1.  定位词：`third paragraph`, `traditional farming method`, `rural Africa`
2.  考点词：`fail to be adopted`（否定结果）；提问方向：`why`（原因）
3.  逻辑简化：传统农耕法 × 非洲推广 + 原因
4.  删除冗余：`According to the third paragraph`, `widely`
✅ 压缩结果：`P3 / traditional farming Africa adoption fail ?`

#### 机考场景的记忆方法
机考无法在题干上划线，压缩结果按以下原则存储：
1.  单道细节题（判断、填空、单选）：**脑记即可**，压缩完带着2-3个关键词立刻回原文定位，做完一题清空再处理下一题。
2.  段落信息匹配、多选题：题干多、信息散，用考场发的草稿纸极简记录，每题只写缩写，不用写完整单词。
3.  新手过渡期：前10次练习可以写在草稿纸上巩固习惯；熟练后必须训练脑内压缩，否则考试时间会不够。

#### 新手常见压缩误区
1.  **只留定位词，丢了考点词**（最常见错误）
    比如判断题只压缩成`NZ native plants`，找到原文后忘了考比较关系，又回头读题干，反而更慢。
    → 纠正：强制用「定位/考点」的双部分格式，两部分缺一不可。
2.  **过度压缩，语义模糊**
    比如把填空题压缩成`1980s / ____`，完全不知道空格前后的逻辑关系。
    → 纠正：至少保留「主体+核心动作」，不能只剩单个单词。
3.  **删掉否定词**（最致命错误）
    把`fail to`, `not`, `lack`这类词删掉，句意直接反转，必错题。
    → 纠正：压缩完先检查「否定、比较、绝对词」三类考点有没有保留。
4.  **保留修饰副词，等于没压缩**
    比如把`significantly reduce`全留下，其实只需要`reduce`就够了，程度副词不影响核心逻辑。

- Day2：50道真题题干，限时5秒/题，全程脑内压缩，不用写出来

### 首次搭配使用的完整流程
当你两个方法都练过基础动作后，第一次合起来做题按这个顺序走，不会混乱：
1.  **3-4分钟**：用结构阅读法梳完全文框架，写好所有段落笔记、标好关键高亮
2.  **1分钟**：快速浏览所有题型，优先做填空题、判断题这类顺序出题的细节题
3.  **单题操作**：3-5秒压缩题干 → 凭结构地图定位到对应段落 → 精读段落找答案句 → 比对考点选出答案
4.  **最后处理主旨题**：段落匹配、List of Headings直接用之前的结构笔记匹配选项，不用重读全文
